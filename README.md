# WhatFraud — 수익률 24시

상금이 있는 공모전 출품용 스마트폰 사기 체험 게임입니다. 평범한 연락에 반응하고 선택의 결과를 겪으며, 하루 끝에 자신의 판단이 흔들렸던 순간을 돌아봅니다.

[공개 데모](https://whatfraud-demo.hoyhoy1227.chatgpt.site)

## 현재와 다음 버전

- 공개 기준: v38의 6사건 버전. 소스 변경과 공개 배포는 별도입니다.
- 이번 구현: 지인 사칭 → 가짜 투자 리딩방 → 피해 회수 사칭의 3막, 주요 앱 5개, 행동 중심 진행, 결말 3개, 개인별 되감기.
- 진행은 이벤트를 재생해 복원하며 가상 송금을 중복 실행하지 않습니다. 본편·짧은 체험·되감기 기록을 분리합니다.
- 실제 기기와 플레이 분량, 출품 규정 확인은 출시 전 검수가 필요합니다. 상세 상태는 ROADMAP.md에서 관리합니다.
- 가상 연락·거래만 다룹니다. 실제 송금·전화 연결은 없으며 AI 없이도 내장 대사로 진행합니다.

## AI와 권리

Gemini 3.5 Flash-Lite는 일부 자유 질문의 NPC 대사만 보조합니다. 사건 사실·거래·진행은 코드가 결정하며 키는 서버의 Sites Secret에만 둡니다. D1 공용 예산과 내장 대사 전환을 사용합니다. 대화 원문은 게임 저장에 남기지 않습니다.

자체 자료는 권리 유보 방식이며 교육·연구·비영리 용도에 한정하지 않습니다. 출품자의 제출·시연·수상·상금 수령과 제3자의 재사용 권한을 구분합니다. 특정 공모전 요강과 전체 자산 증빙은 아직 확인이 필요합니다.
