# WhatFraud — 수익률 24시

투자·도박 관련 스마트폰 연락을 `정상 / 주의 / 사기`로 판별하는 교육용 웹 게임입니다.

## 현재 구현된 기능

- 스마트폰 메신저를 중심으로 진행되는 12개 판별 사례
- 사건 판정 후 시간이 흐르며 다음 연락이 하나씩 도착하는 순차 진행
- 오전·오후·밤의 3막에 따라 시간·배경 톤·사건 압박이 달라지는 하루 연출
- 현재 연락과 함께 도착하는 전화·SNS·달력·증권 앱의 주변 알림과 이전 선택의 후속 변화
- 기본 시작은 긴 설명 없이 평소 휴대폰처럼 잠금 화면의 알림부터 확인하고, 필요할 때만 선택해 보는 7단계 게임 안내
- 첫 잠금 화면에서는 게임 HUD를 숨기고, 현재 목표는 잠금 해제·연락 확인·근거 발견 같은 상황 변화 때만 잠시 나타났다 사라지는 몰입형 진입
- 어느 화면에서든 여는 하단 `판정하기` 메뉴와 앱별 `i` 도움말
- 대화형 DM, 읽기 전용 공식 안내, 일방형 문자·광고 링크를 구분한 현실적인 연락 화면
- 정상 금융 알림, 위험하지만 사기는 아닌 권유, 투자리딩방·도박 예측방·피해금 회수 사기 혼합
- AI 영상·유명인 사칭 투자광고, 해외 비상장주식·공모주 대행, 국제대회 불법도박 유인 등 최신 유형 추가
- 상대에게 자유롭게 질문하는 Gemini 3.6 Flash 보조 대화
- 질문이 이어질수록 NPC가 신뢰 유도에서 재촉으로 미묘하게 변하는 단계형 대화 연출
- 마을과 캐릭터 없이 잠금 화면부터 모든 플레이가 이어지는 스마트폰 전용 구성
- `휴대폰을 확인해 보세요` 한 문장과 열기 버튼만 강조한 간결한 시작 화면
- 잠금 화면, 시간·날짜, 알림 카드, 홈 화면, 배경화면, 앱 그리드와 하단 독을 갖춘 휴대폰 UX
- 메시지 말풍선·전화 수화기·은행 건물·증권 차트·브라우저 나침반 등 12개 앱의 기능을 직접 표현하는 공통 벡터 아이콘
- 메시지나 주변 앱 알림을 한 번 열면 잠금·홈 화면의 알림과 배지가 사라지고, 새 판정이 생겼을 때만 안전센터 알림이 다시 나타나는 읽음 처리
- 도트 그래픽 대신 실제 모바일 금융·메신저 앱을 참고한 차분한 색상, 앱별 아이콘과 자연스러운 카드 디자인
- 메시지·전화·가상 은행·가상 증권·브라우저·SNS·달력·메모·연락처·안전센터·설정·사진 앱
- 내 알림 기록·은행 앱·저장된 연락처·공식 신고 조회·업체와 공시 검색을 통한 앱 간 교차 확인
- 뒤로·홈·판정하기를 언제든 사용할 수 있는 휴대폰 시스템 메뉴
- 판정 근거, 실제 대응 행동, 확신도와 공식 확인을 함께 반영하는 점수 시스템
- 판정 후 연락 도착부터 공식 확인·판정까지 실제 게임 시간 순서로 보여 주는 사건 되감기
- 안전센터의 완료 판정 기록, 선택 결과 시뮬레이션과 하루 종료 플레이 성향 평가
- Gemini 키 누락·무료 한도·서버 제한·16초 지연에도 이어지는 내장 대체 응답
- 설정 화면에서 확인하는 Gemini 연결 상태·최근 응답 시간·대체 전환 이유
- 실제 화면 자산 준비율을 보여주는 시작 로딩, 사건별 시간 경과 전환과 AI 응답 대기 안내
- 스마트폰 앱 실행 화면, 새 메시지 수신 알림과 메신저 입력 중 말풍선으로 구성한 자연스러운 대기 연출
- 사건 진행·조사·판정만 기기에 자동 저장하고 타이틀에서 안전하게 이어하는 기능(자유 입력 대화·AI 답변은 저장하지 않음)
- 사건별 실제 유형 근거·가상화 범위·독립 확인 경로·학습 목표·안전 감사를 담은 콘텐츠 검수표
- 12개 사건 순차 진행, 점수, Gemini 서버 격리, 키보드·모바일 접근성을 확인하는 출시 전 자동 검사

전체 구현 순서와 연락 표현 원칙은 [ROADMAP.md](ROADMAP.md)에 정리되어 있습니다.

## 시나리오 추가와 검증

각 사건은 `content/cases/*.json`에 독립된 파일로 저장됩니다. 새 사건 파일을 추가하거나 기존 내용을 수정한 뒤 다음 명령으로 필드와 안전 규칙을 검사하고 게임용 데이터로 통합합니다.

```bash
pnpm content:build
pnpm content:check
pnpm dialogue:check
pnpm release:check
```

콘텐츠 검사기는 중복 ID, 누락된 대화·복기 필드, 독립 확인 경로 부족, 실제 접속 URL, `.invalid`가 아닌 링크와 판정·연락 유형 불균형을 차단합니다. 대화 검사기는 후보 응답의 위험 패턴, 주제 편중과 사건 간 완전 중복을 확인합니다. 필드 정의는 `content/schema/case.schema.json`에서 확인할 수 있습니다.

사건별 제작 검수 항목과 작성 방법은 [CONTENT_REVIEW.md](CONTENT_REVIEW.md)에 정리되어 있습니다. `pnpm dialogue:check`는 네 대화형 사건의 검수된 후보 대사를 대상으로 길이·안전 경계·반복 문제를 검사합니다.

## Gemini 무료 등급 보조 AI

공개 게임은 대화형 사건에서만 Google Gemini API를 호출합니다. 서버 환경 변수 `GEMINI_API_KEY`가 있으면 Gemini 3.6 Flash가 최소 생각 수준으로 짧은 NPC 답변을 만들고, 키가 없거나 무료 할당량·게임 제한·안전 검사를 통과하지 못하면 검수된 후보 대사로 자동 전환합니다.

```text
방문자 브라우저 → /api/ai-chat → Gemini 3.6 Flash
                         ↓ 키·한도·안전 검사 실패
                   검수된 내장 후보 대사
```

브라우저에는 키가 전달되지 않습니다. 서버는 사건 ID와 최근 메시지만 받고 모델·시스템 역할·출력 길이를 고정하며, 개인정보 형태를 제거하고 답변을 다시 검사합니다. 발급·로컬 설정·Sites Secret·교체 절차는 [API_KEY_MANAGEMENT.md](API_KEY_MANAGEMENT.md)에 정리했습니다.

## 게임 실행

Node.js 22 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

프로젝트 루트의 `.env.example`을 참고해 `.env.local`에 `GEMINI_API_KEY`를 넣으면 로컬 보조 AI가 활성화됩니다. 키 없이도 내장 대체 응답으로 모든 사례를 플레이할 수 있습니다.

## 콘텐츠 원칙

- 실제 피해 사례에서 반복되는 심리 조종 구조를 합성해 사용합니다.
- 실제 계좌번호·작동 링크·악성 앱·실존 피해자의 개인정보는 포함하지 않습니다.
- Gemini는 대사만 생성하며 사건의 정답과 점수는 코드가 결정합니다.
- 사기범 역할의 모델은 게임 밖에서 사용할 수 있는 범죄 실행 방법을 생성하지 않도록 제한합니다.
