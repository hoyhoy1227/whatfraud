## AI와 권리

Gemini 3.5 Flash-Lite는 일부 자유 질문의 NPC 대사만 보조합니다. 사건 사실·점수·진행은 코드가 결정하며 키는 서버의 Sites Secret에만 둡니다. D1 공용 예산과 내장 대사 전환을 사용합니다. 대화 원문은 게임 저장에 남기지 않습니다.

자체 자료는 권리 유보 방식이며 교육·연구·비영리 용도에 한정하지 않습니다. 출품자의 제출·시연·수상·상금 수령과 제3자의 재사용 권한을 구분합니다. 특정 공모전 요강과 전체 자산 증빙은 아직 확인이 필요합니다.
