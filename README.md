# WhatFraud — 수익률 24시

투자·도박 관련 스마트폰 연락을 `정상 / 주의 / 사기`로 판별하는 교육용 웹 게임입니다.

## 현재 구현된 기능

- 스마트폰 메신저를 중심으로 진행되는 8개 판별 사례
- 정상 금융 알림, 위험하지만 사기는 아닌 권유, 투자리딩방·도박 예측방·피해금 회수 사기 혼합
- 상대에게 자유롭게 질문하는 로컬 Qwen 대화
- 마을과 휴대폰을 각각 전체 화면으로 여는 자유로운 화면 전환
- 전용 타이틀 배경과 `시뮬레이션 시작` 버튼이 있는 게임 시작 화면
- 잠금 화면, 시간·날짜, 알림 카드, 홈 화면, 배경화면, 앱 그리드와 하단 독을 갖춘 휴대폰 UX
- 메시지·전화·가상 은행·가상 증권·브라우저·SNS·달력·메모·연락처·안전센터·설정·사진 앱
- 집·은행·카페·경찰서·도서관을 조사하는 클래식 휴대용 게임기풍 2D 도트 마을
- 프로젝트를 위해 새로 생성한 오리지널 마을 지도, 플레이어, 시작 화면, 휴대폰 배경과 앱 아이콘 자산
- 판정 확신도와 공식 확인 행동을 반영하는 점수 시스템
- 판정 후 위험 신호와 권장 행동 복기
- Qwen이 실행되지 않아도 플레이 가능한 내장 대체 응답

## 유료 API를 사용하지 않습니다

게임은 OpenAI 서비스나 다른 유료 API에 접속하지 않습니다. 화면에 표시된 `OpenAI 호환` 형식은 통신 규격의 이름일 뿐입니다.

```text
Hugging Face Qwen3.5-4B
       ↓ 선택 사항: LoRA 튜닝
GGUF 4비트 양자화
       ↓
사용자 PC의 llama.cpp (127.0.0.1:8080)
       ↓
브라우저 게임
```

대화 내용은 사용자의 컴퓨터 안에서 처리됩니다. Qwen 모델 가중치와 튜닝 결과는 용량 때문에 이 저장소에 포함하지 않습니다.

## 게임 실행

Node.js 22 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

로컬 Qwen 없이도 내장 대체 응답으로 모든 사례를 플레이할 수 있습니다.

## 로컬 Qwen 연결

1. Hugging Face의 `Qwen/Qwen3.5-4B`를 GGUF 형식으로 준비합니다.
2. llama.cpp의 `llama-server`를 `127.0.0.1:8080`에서 실행합니다.
3. 게임의 `로컬 모델 설정`에 `http://127.0.0.1:8080/v1/chat/completions`를 입력합니다.

이번 기본 버전에는 모델 튜닝 코드나 모델 가중치를 포함하지 않습니다.

## 콘텐츠 원칙

- 실제 피해 사례에서 반복되는 심리 조종 구조를 합성해 사용합니다.
- 실제 계좌번호·작동 링크·악성 앱·실존 피해자의 개인정보는 포함하지 않습니다.
- LLM은 대사만 생성하며 사건의 정답과 점수는 코드가 결정합니다.
- 사기범 역할의 모델은 게임 밖에서 사용할 수 있는 범죄 실행 방법을 생성하지 않도록 제한합니다.
