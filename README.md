# 사기방지위원회

평범한 스마트폰 연락에서 시작해, 확인과 선택이 남긴 결과를 돌아보는 인터랙티브 사기 체험 게임입니다.

**[공개 데모 플레이](https://whatfraud.hoyhoy1227.chatgpt.site/)** · [게임 안내](docs/PUBLIC_DEMO.md) · [개발 시행착오](docs/DEVELOPMENT_JOURNEY.md)

## 어떤 게임인가요?

| 흐름 | 체험 |
| --- | --- |
| 아침 · 지인 사칭 | 익숙한 이름의 부탁을 받고 기존 연락처와 수취인 기록을 확인합니다. |
| 낮 · 가짜 투자 자료방 | 무료 요약·유료 분석 자료 안내를 은행·독립 확인 기록과 비교합니다. |
| 저녁 · 피해 회수 사칭 | 앞선 선택이 남긴 상황에서 추가 비용 요청에 대응합니다. |
| 하루 끝 | 행동 근거가 담긴 대응 보고서와 결말을 보고, 주요 선택 이전으로 되감아 다른 대응을 시도합니다. |

- 메시지·전화·은행·브라우저·메모를 오가며 자료를 읽고 보관합니다.
- 가상 송금, 독립 확인, 보류, 차단, 기록 보관·접수 등의 행동으로 진행합니다.
- 본편 이어하기와 투자 자료방부터 시작하는 짧은 체험을 제공합니다.
- AI는 선택적인 인물 답장만 보조합니다. 사건별 2/2/1회, 실행 최대 5회이며 AI 없이도 완주할 수 있습니다.
- 음악·효과음의 음량, 큰 글자·동작 줄이기·일시정지 설정을 제공합니다.
- 모든 인물과 거래는 허구입니다. 실제 송금·전화 연결·신고 접수는 하지 않습니다.
