## 첨부·AI·대응 보고서

- 확인 가능한 제작 기록을 첨부·대조·보관합니다. 사용자 파일을 업로드하는 기능이 아닙니다.
- 결정 직전 메시지와 지수·준호 메시지 등 지정된 장면에서만 선택적으로 AI를 사용합니다.
- 사건별 상한은 2/2/1, 새 실행 전체 최대 5회입니다. 실패·취소된 시도도 사용량에 남을 수 있습니다.
- 동의 화면은 허구·전송·개인정보·5회 한도를 안내합니다. 나이 확인 절차는 없습니다.
- 보고서는 실제 선택·첨부·대화 분기·확인 순서에서 작성하며, 추가 분석 API를 호출하지 않습니다.
- AI 의도 분류와 실제 게임 행동을 구분합니다. 답장만으로 송금·신고·환급을 실행하지 않습니다.

## 저장과 되감기

- 본편과 짧은 체험은 별도 저장 키를 사용합니다.
- 저장은 기기 내부의 허용된 행동 이벤트를 사용합니다. 잔액·결말은 복원 과정에서 다시 계산합니다.
- 자유 입력과 생성 답장의 원문은 진행 저장에 남기지 않습니다. 새로고침 뒤에는 범주 기반 요약으로 보일 수 있습니다.
- 되감기는 원본 저장을 덮어쓰지 않는 별도 시도이며 AI 생성을 사용하지 않습니다.
- 저장 키 이름은 `whatfraud-story-v3`를 유지하고, 직렬화 버전 4 및 이전 v3 이벤트 호환 처리를 사용합니다.
- 인물 연락은 해당 사건에서 마무리하고, 이전 사건의 기록은 메모에서 보존합니다.
