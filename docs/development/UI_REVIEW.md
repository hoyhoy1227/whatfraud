# 사기방지위원회 — UI 개선 근거와 검수 기준

목적: 코드에 반영된 개선과 아직 사람이 확인해야 할 화면 검수를 구분합니다. 전체 개발 과정은 [시행착오](DEVELOPMENT_JOURNEY.md), 우선순위는 [ROADMAP](ROADMAP.md)에 둡니다.

## 이번 문서 정리의 확인 범위

- 브라우저 직접 검토·화면 캡처·실기기 조작·실제 Gemini 호출은 수행하지 않습니다.
- 소스와 기존 검사 스크립트로 화면 구조·문구·동작 조건을 확인합니다.
- 과거 문서의 부분 화면 캡처·자동 검사 성공을 현재 전체 화면의 합격으로 취급하지 않습니다.
- 현재 실행 파일은 공개 v76 기준으로 맞췄습니다. [기준표](../game/PUBLIC_DEMO.md#공개-데모와-저장소의-기준)의 소스로 검수합니다.

## 반영된 개선과 근거

| 문제 | 코드의 대응 | 관련 파일·검증 |
| --- | --- | --- |
| 홈·목록·본문 미리보기 불일치 | 표시 메시지에서 미리보기 계산, 발신자·대화별 상태 구분 | `presentation.js`, `story-client.tsx`, UI/진행 검사 |
| 화면을 열기만 해도 읽음으로 처리 | 대화·단계·표시 위치 및 실제 열람 조건 확인 | `story-client.tsx`의 읽음 처리 |
| 초안 입력과 새 수신의 스크롤 혼동 | 전송 완료·표시 메시지 기준 감시와 읽던 위치 분리 | `story-client.tsx`, UI 소스 회귀 |
| 작성 대화와 선택·결정 답장의 순서 혼동 | 시간순 대화 통합과 결정 답장의 단계 고정 | v76 `7aadfed`, `test-message-transcript.mjs` |
| 여러 문장 동시 노출·인물 혼동 | 문장별 말풍선·표시 간격·연속 발신자 표현 | `chat-bubbles.tsx`, `message-pacing.js` |
| 프로필 조회와 확인 요청 혼동 | 프로필 표시·저장된 번호/새 계정 구분, 확인 행동 분리 | `presentation.js`, `story-client.tsx` |
| 좁은 화면의 긴 문구·하단 도크 | 의미 단위 줄바꿈·독립 행동 영역·안전영역·viewport 높이 | `globals.css`, `story-client.tsx` |

위 표는 구현 근거입니다. CSS·SSR·소스 검사는 실제 키보드·터치·픽셀 배치를 보증하지 않습니다.

## 기록 방법

- 소스 SHA·배포 버전·기기/브라우저·화면 크기·검수 경로를 함께 기록합니다.
- 소스 검사, SSR, 실제 화면, 실제 AI 응답을 별도 결과로 남깁니다.
- 실패 시 재현 단계·예상 결과·실제 결과를 적고, 수정 후 같은 경로를 다시 확인합니다.
- 공개 데모를 검토하지 않은 변경에는 공개 화면 검수 완료 표시를 추가하지 않습니다.
